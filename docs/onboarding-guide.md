# Guided first session

The main terminal includes a seven-stop guide: welcome, markets, agent setup, conversation, portfolio, controls, and community. New visitors see it automatically after account state loads. Existing users can choose “Show me around.” The guide can collapse, skip, resume, and replay. Non-sensitive progress is saved in this browser, separated by signed-in address for hosted accounts. It does not save recovery keys or chat content.

The market stop waits for a token page. Agent setup remains inside the existing creation flow, including recovery backup. The conversation action prepares a question and leaves Send to the user. A successful reply enables the next stop; “Try chat later” lets users continue when a provider is unavailable. Completing the tour means finishing the introduction, not proving that trading is active.

New agents open with Trencher selected. “Start live Trencher” enables the complete live preset and includes Autonomous Trencher in the first wallet permission; “Practise first” keeps both live switches off. The screen shows the planned $2.50 entry, the vault's $5 buy / $25 daily ceiling, and the unchanged signed limits before either action. Wallet approval and funding are still required. Other strategies and custom limits remain under “Customise strategy and limits”. Existing agents keep their saved strategy and wallet.

Protected Privy wallets proceed directly to funding after successful activation, with a reminder to retain access to their sign-in account. Legacy wallet recovery backup stays in place. A failed activation retries the same saved permission with fresh authentication; it does not create another wallet or ask for another signature. Live onboarding funding opens through the desktop sidebar.

Existing agents can use “Enable live Trencher” in Settings to save the strategy, discovery, fast exits and both live switches in one action. This changes no wallet or signed limit. Missing, expired or outdated permissions still need their owner's approval. A saved setting is not proof that the worker is trading: service admission, receipt-backed accounting, funding, eligible pools and Brain approval must also pass.
