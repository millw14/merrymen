# Guided first session

The main terminal includes a seven-stop guide: welcome, markets, agent setup, conversation, portfolio, controls, and community. New visitors see it automatically after account state loads. Existing users can choose “Show me around.” The guide can collapse, skip, resume, and replay. Non-sensitive progress is saved in this browser, separated by signed-in address for hosted accounts. It does not save recovery keys or chat content.

The market stop waits for a token page. Agent setup remains inside the existing creation flow, including recovery backup. The conversation action prepares a question and leaves Send to the user. A successful reply enables the next stop; “Try chat later” lets users continue when a provider is unavailable. Completing the tour means finishing the introduction, not proving that trading is active.

Strategy choices include labelled examples. Paper trading is recommended. Live onboarding funding opens through the desktop sidebar. The guide explains the actual wallet-permission controls rather than promising that chat can pause trading.
